# Campus Placement & Recruitment Tracker

A custom scoped ServiceNow application designed to manage student placement drives, eligibility criteria, interview rounds, and application workflows.

## 🚀 Key Features & Architecture
- **Data Model:** Custom tables for `Student Profile`, `Company Drive`, and `Placement Application`.
- **User Interface & Portal:** Record Producers for seamless student enrollment and placement applications.
- **Automation & Workflows:** Flow Designer actions to automate status updates and student email notifications.
- **Form Intelligence:** UI Policies and Client Scripts for dynamic input validation and state management.
- **Security:** Scoped Access Control Lists (ACLs) ensuring role-based privacy between students and coordinators.

## 🛠️ Built With
- ServiceNow Platform (Vancouver / Washington DC)
- Scoped Application Architecture
- JavaScript & Glide API
